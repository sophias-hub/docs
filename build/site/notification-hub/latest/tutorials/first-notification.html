Tutorial: Send your first notification

This tutorial walks you through making your first successful request to the Notification Hub API.

Before you begin

  • Ensure the API is running locally:

    npm install
npm start

    The API should be available at http://localhost:3000.

Step 1: Set your API key

This demo uses a static API key.

export API_KEY="secure-token-123"

Step 2: List templates

curl -s \
  -H "X-API-Key: ${API_KEY}" \
  http://localhost:3000/api/v1/templates

Step 3: Send a notification

curl -s \
  -H "Content-Type: application/json" \
  -H "X-API-Key: ${API_KEY}" \
  -d '{
    "recipient": "user@example.com",
    "channel": "email",
    "templateId": "welcome-email",
    "templateData": { "name": "Sophia" }
  }' \
  http://localhost:3000/api/v1/send

Troubleshooting

  • If you get 401, see Authenticate requests.

  • If you get 400, see Errors.

How-to: Send a notification

Use POST /api/v1/send to send a notification using a template.

Request shape

  • recipient (required)

  • channel (required): email | sms | push

  • templateId (required)

  • templateData (optional)

Example request

curl -s \
  -H "Content-Type: application/json" \
  -H "X-API-Key: secure-token-123" \
  -d '{
    "recipient": "user@example.com",
    "channel": "email",
    "templateId": "welcome-email",
    "templateData": { "name": "Sophia" }
  }' \
  http://localhost:3000/api/v1/send

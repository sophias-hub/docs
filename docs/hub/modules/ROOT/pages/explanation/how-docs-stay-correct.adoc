= Explanation: How docs stay correct

This portfolio project is set up to demonstrate a docs-as-code workflow.

== Sources of truth

* API behavior: `notification-hub-service/src/server.ts` and automated tests (`notification-hub-service/src/server.test.ts`)
* API reference: generated OpenAPI (`tsoa spec` → `notification-hub-service/docs/api/swagger.json`)
* SDK reference: generated TypeDoc (`typedoc` → `notification-hub-service/docs/sdk/`)

== CI gates (target state)

* Builds must succeed.
* Tests must pass.
* OpenAPI generation must succeed and be validated.
* Docs hub build must succeed, with link/style checks enabled.

== AI/agent policy (target state)

* Agents may propose updates via PRs with diffs.
* Human-authored guides are reviewed by a human before merging.
* Generated artifacts may be auto-updated only when the output is deterministic and validation passes.

= Reference: API

The API reference is published as an OpenAPI (Swagger) document.

== Swagger UI (local)

When running the API repo’s docs command, Swagger UI is available at:

* `http://localhost:8080/docs` (from `notification-hub-service`)

== OpenAPI source

* `docs/api/swagger.json` (generated in the API repo)

NOTE: In the portfolio target state, Swagger UI is deployed as a site that fetches `swagger.json` from the latest successful `main` build of the API repo.

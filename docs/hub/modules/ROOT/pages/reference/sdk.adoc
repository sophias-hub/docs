= Reference: SDK

The SDK reference is generated with TypeDoc in the API repo.

== Local build (from the API repo)

[source,bash]
----
cd "../notification-hub-service"
npm run docs:sdk
----

The generated site is written to `docs/sdk/` in the API repo.

NOTE: In the portfolio target state, the SDK reference is deployed as a separate site (for example, GitHub Pages) and linked from this hub.

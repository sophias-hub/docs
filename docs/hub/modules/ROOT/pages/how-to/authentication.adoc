= How-to: Authenticate requests

All API requests require an API key in the `X-API-Key` header.

== Set your API key (local demo)

[source,bash]
----
export API_KEY="secure-token-123"
----

== Use the header in requests

[source,bash]
----
curl -s \
  -H "X-API-Key: ${API_KEY}" \
  http://localhost:3000/api/v1/templates
----

== Common issues

* Missing `X-API-Key` header: results in `401 Unauthorized`.
* Incorrect key: results in `401 Unauthorized`.

== Create and confirm the template

A {gt-template} is the reusable message you want to send. The service needs one set up before it can send a notification.

To create a template, follow these steps:

. Open the _Create template_ endpoint below.
. Fill in the request following the example request payload.
+
include::ROOT:partial$rapi-doc-mini.adoc[tag=templates-create]
+
. Click *Try* and *Execute* to create the template.
. See the endpoint response to verify successful template creation.
. Keep the service-assigned template `id` for later tutorial steps.

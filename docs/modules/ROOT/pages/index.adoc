= Notification Hub Documentation
:description: Start here for what Notification Hub is, how it works, and which guide to open next.

include::glossary:partial$attributes.adoc[]

{gt-notification-hub} is a dispatch service your application calls when it needs to notify a person. A {gt-sender} asks it to deliver a message to a {gt-recipient} on email, SMS, or push—for example after signup, for a one-time password, or when a payment succeeds.

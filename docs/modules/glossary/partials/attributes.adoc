:glossary-def-sender: The application that authenticates to Notification Hub, manages templates and preferences, sends notifications, looks up delivery records, and receives webhooks.
:glossary-def-recipient: The person Notification Hub notifies on a channel (email, SMS, or push).
:glossary-def-notification-hub: The notification dispatch service that stores templates and preferences, accepts sends, creates delivery records, and optionally delivers webhook events.
:glossary-def-template: A reusable message definition with a stable id, a name, and a single channel (email, SMS, or push).
:glossary-def-preferences: Per-Recipient flags that allow or block each channel. true allows sends; false blocks them.
:glossary-def-channel: A delivery path Notification Hub supports: email, SMS, or push.
:glossary-def-record: The delivery tracking object returned when a send is accepted. Look up status by recordId.
:glossary-def-delivery-status: Demo lifecycle values on a record: accepted, queued, delivered, or failed.
:glossary-def-webhook: A callback URL the Sender registers so Notification Hub can post delivery events.
:glossary-def-api-key: The header value a Sender sends to authenticate business operations (X-API-Key).

:glossary-def-channel: A delivery path Notification Hub can use to deliver a notification to a Recipient.
:glossary-def-delivery-status: A lifecycle value on a sent notification record, showing whether it is queued, delivered, or failed.
:glossary-def-notification: The message a Sender asks Notification Hub to deliver to a Recipient on a channel.
:glossary-def-notification-hub: The notification dispatch service that stores templates and preferences, accepts sends, and creates delivery records.
:glossary-def-preferences: Per-Recipient flags that allow or block sending notifications to each channel.
:glossary-def-recipient: The person Notification Hub notifies on a channel.
:glossary-def-record: The notification delivery tracking object returned when a send is accepted.
:glossary-def-sender: The application that manages templates and preferences, sends notifications, and looks up delivery records.
:glossary-def-template: A reusable message definition.

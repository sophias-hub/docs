Use this how-to when you need recent send {gt-record} entries for one {gt-recipient}.

== What you need

* A valid `X-API-Key` (try-out key is prefilled)
* The Recipient identifier

== List records with filters

Filter by `recipient` and optionally by `status`.

== When to use this

* Confirm which sends reached a Recipient after a campaign or support request.
* Filter by status (for example `delivered` or `failed`) to narrow the list.

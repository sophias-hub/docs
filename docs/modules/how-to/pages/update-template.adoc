= Update a template
:description: How to replace or partially update a Notification Hub template.

Use this how-to when you need to change an existing {gt-template}’s name, {gt-channel}, or content without creating a new id.

== What you need

* A valid `X-API-Key` (try-out key is prefilled)
* An existing template `id`

= Connect with an API key
:description: How to authenticate Notification Hub requests with the X-API-Key header.


include::glossary:partial$attributes.adoc[]

Notification Hub protects business operations—the {gt-template} catalog, {gt-preferences}, sends, delivery {gt-record} lookups, and {gt-webhook} registration—with an {gt-api-key}.
A {gt-sender} passes the key in the `X-API-Key` header before any authenticated try-it-out step in these guides.

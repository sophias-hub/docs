= Send a notification
:description: How to send a Notification Hub notification when template and preferences are ready.

include::glossary:partial$attributes.adoc[]

Use this how-to guide to send a {gt-notification} with a {gt-template} and allowed {gt-preferences}.

include::ROOT:partial$mock-service-note.adoc[]

== Prerequisites

include::ROOT:partial$try-out-key-prereq.adoc[]
* You have a {gt-recipient} identifier, a {gt-channel}, and an existing template `id`
* {gt-preferences} allow that channel for the {gt-recipient}

== Limitations

* Match `channel` to the template channel and an allowed preference.

WARNING: To keep the service stable, the limit of **10** sends per **60 seconds** must not be exceeded.

== Send a notification

. Open the _Send notification_ endpoint below.
. Fill in the request following the example request payload or schema.
+
include::ROOT:partial$rapi-doc-mini.adoc[tag=send]
+
. Click *Try* and *Execute*.
. See the endpoint response and copy the `recordId`.

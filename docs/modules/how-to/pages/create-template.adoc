= Create a template
:description: How to add a reusable notification template to the Notification Hub catalog.


include::glossary:partial$attributes.adoc[]

Use this how-to when you need to add a reusable notification {gt-template} to the catalog.
A template is a named definition for one {gt-channel} (email, SMS, or push) that later sends can reference.

== What you need

* A valid `X-API-Key` (try-out key is prefilled)
* A template `id`, display `name`, and `channel` (`email`, `sms`, or `push`)

include::ROOT:partial$try-out-key-note.adoc[]

== Limitations

* The template `id` must be unique in the catalog.
* Use a stable `id` (for example `welcome-email`) so a {gt-sender} can keep referring to it.
